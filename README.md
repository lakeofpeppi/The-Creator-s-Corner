# 🎀 The Creator's Corner

### Your creative world, beautifully organized.

**The Creator's Corner** is an interactive, all-in-one content planning and management web application designed for content creators who want to turn their creative ideas into reality.

Inspired by the organization of Notion, the visual creativity of Pinterest, and modern social media management tools, this project brings content planning, inspiration, and productivity into one personalized digital workspace.

## ✨ Features

### 🏠 Personalized Dashboard
A creative headquarters for viewing content statistics, upcoming posts, and overall content production progress.

### 📋 Content Pipeline
An interactive Kanban-style workflow for organizing content through five stages: Ideas, Planning, Creating, Scheduled, and Published.

### 📅 Content Calendar
A monthly planning calendar for organizing upcoming posts and managing content schedules.

### 📌 Inspiration Moodboard
A visual workspace for collecting creative references, inspiration, and content ideas.

### 💌 Caption & Hashtag Library
A dedicated library for organizing reusable captions and hashtags across social media platforms.

### 📊 Performance Analytics
A dashboard for tracking manually entered engagement metrics, including views, likes, comments, shares, and saves.

### 🎨 Personalization
A customizable creator workspace with personal settings and browser-based data storage.

## 🛠️ Technologies

- **HTML5:** Website structure
- **CSS3:** Styling, layout, and responsive design
- **JavaScript:** Interactive functionality and dynamic content
- **LocalStorage:** Browser-based data persistence
- **GitHub Pages:** Website deployment and hosting

The application is developed as a single `index.html` file without requiring a backend or database.

## 🌷 Project Purpose

This project was developed as part of a university **Vibe Coding assignment**, exploring how artificial intelligence can assist in transforming a creative concept into a functioning web application.

The development process focuses on:
1. Brainstorming and defining the website concept.
2. Developing detailed functional and visual specifications with AI.
3. Implementing the website through AI-assisted coding.
4. Testing, refining, and improving the application.
5. Publishing the completed website through GitHub Pages.

## 💻 Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Start organizing your creative projects!

No installation or additional dependencies are required.

## 🌐 Live Website

[Visit The Creator's Corner](https://lakeofpeppi.github.io/The-Creator-s-Corner/)

## 📝 Notes

The Creator's Corner is a front-end demonstration project. Content management and analytics are handled locally in the browser rather than through direct integrations with social media platforms.

## 💗 Project Vision

*Create freely. Plan beautifully. Stay inspired.*

The Creator's Corner aims to make the content creation process feel less overwhelming and more intentional, turning everyday creativity into an organized and enjoyable experience.
